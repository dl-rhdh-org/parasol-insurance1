# Claims API

This component **provides** the catalog API entity `parasol-insurance-api`.

In Developer Hub:

1. Open this component → **Relations** / Overview and follow **provides API**.
2. Or go to Catalog → kind **API** → **parasol-insurance-api**.
3. Use the **Definition** tab for the interactive OpenAPI view (list/create/get/update claims).

The OpenAPI document is registered in `rhdh-repo` under `catalog-entities/parasol-insurance-api.yaml` (workshop-style Claims API, expanded for the demo browser).
